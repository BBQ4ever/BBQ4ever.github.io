Jarvis Privacy Policy

Last updated: 2026-09-28 · Jarvis home · 中文

What Jarvis is

Jarvis is a personal live-streaming assistant. It is made and used only by the owner of the BBQ4ever YouTube channel, and it runs only on the owner's own computer. It is not offered to the public.

YouTube API Services

Jarvis uses YouTube API Services. By using Jarvis you agree to be bound by the YouTube Terms of Service. Google's handling of data is described in the Google Privacy Policy.

What information Jarvis accesses

Only after the channel owner signs in with Google and grants access, Jarvis may:

  • read the details of the owner's own live broadcasts and videos, and update their title, description, tags, language settings and thumbnail;
  • update the owner's own channel description and keywords;
  • read the live chat of the owner's own live streams (the message text and the display name shown next to it), and post messages to that chat as the owner.

How the information is used, stored and shared

  • Everything is used only to run the owner's own live streams.
  • The sign-in token, logs (including chat messages Jarvis has read) and usage counters are stored only on the owner's computer. They are not uploaded anywhere else.
  • Information is never sold, never used for advertising or tracking, and never shared with anyone, with one exception: when the owner turns on "read chat aloud", the text of a chat message (display name and up to 80 characters of the message) is sent to Microsoft's online text-to-speech service to create audio that plays only on the owner's own speakers.

Cookies, ads and third-party content

Jarvis and this website use no cookies, no analytics, no ads and no third-party content. This website is hosted on GitHub Pages; GitHub may process technical data about visits as described in the GitHub Privacy Statement.

How to revoke access

You can remove Jarvis's access to your Google account at any time on the Google security settings page: myaccount.google.com/permissions.

Contact

Questions or complaints about these privacy practices: please open an issue at github.com/BBQ4ever/BBQ4ever.github.io/issues.

Changes

If this policy changes, the new version will be posted on this page with a new date.

Jarvis 隐私政策

更新日期:2026-09-28

Jarvis 是什么

Jarvis 是一个个人直播助手,由 BBQ4ever YouTube 频道的主人自己制作、只给自己用,只在主人自己的电脑上运行,不对外提供。

YouTube API 服务

Jarvis 使用 YouTube API 服务。使用 Jarvis 即表示同意遵守 YouTube 服务条款。Google 如何处理数据见 Google 隐私权政策。

Jarvis 会访问哪些信息

只有在频道主人用 Google 登录并授权之后,Jarvis 才会:

  • 读取主人自己的直播和视频的信息,并修改它们的标题、简介、标签、语言设置和封面;
  • 修改主人自己频道的简介和关键词;
  • 读取主人自己直播间的聊天(消息内容和旁边显示的昵称),并以主人身份在该聊天里发消息。

信息怎么用、存在哪、给不给别人

  • 全部只用来运行主人自己的直播。
  • 登录令牌、日志(包括读到的聊天消息)和用量计数只存在主人自己的电脑上,不上传到别处。
  • 不出售、不用于广告或追踪、不给任何人。唯一的例外:主人打开「读聊天」时,一条聊天消息的文字(昵称和最多 80 个字)会发给微软的在线语音合成服务,生成的声音只在主人自己的扬声器上播放。

Cookie、广告和第三方内容

Jarvis 和本网站不用 Cookie、不做统计、没有广告、没有第三方内容。本网站托管在 GitHub Pages 上,GitHub 可能按 GitHub 隐私声明处理访问的技术数据。

怎么撤销授权

随时可以在 Google 安全设置页面移除 Jarvis 对你 Google 账号的访问:myaccount.google.com/permissions。

联系

对隐私做法有疑问或投诉,请在 github.com/BBQ4ever/BBQ4ever.github.io/issues 提一个 issue。

变更

本政策有变动时,新版本会发在本页并更新日期。
