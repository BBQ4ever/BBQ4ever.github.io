Jarvis

BBQ4ever · Privacy Policy / 隐私政策

Jarvis is a personal live-streaming assistant used only by the owner of the BBQ4ever YouTube channel. It runs on the owner's own computer and helps with the owner's own live streams: it keeps the stream's title, description and thumbnail up to date, and reads the live chat so the owner does not have to watch the screen. It is not offered to the public.

Jarvis uses YouTube API Services. By using Jarvis you agree to be bound by the YouTube Terms of Service. See the Jarvis Privacy Policy and the Google Privacy Policy.
